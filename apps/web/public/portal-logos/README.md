# Portal logos

Logos for the landing page's "Where it works" cards. Add the official file for each portal here,
named as below (`.svg` preferred; `.png` and `.webp` also work). Square or near-square artwork
with a transparent or white background looks best. Rebuild afterwards: the landing page is static.

| File name (without extension) | Portal |
| --- | --- |
| `indian-railways` | Indian Railways (SSC uses `/ssc-logo.png` already) |
| `nsp` | National Scholarship Portal |
| `e-district` | e-District |
| `workday`, `greenhouse` | Workday, Greenhouse |
| `linkedin`, `indeed` | LinkedIn, Indeed |
| `naukri`, `shine` | Naukri, Shine |
| `cuet` | CUET |
| `salesforce`, `zoho` | Salesforce, Zoho |

A missing file is skipped and the card keeps its icon. The mapping lives in
`lib/landing/where-it-works.ts` (`PORTAL_LOGOS`).

These are third-party trademarks. Use each owner's published brand assets and follow their
usage guidelines (the Emblem of India is restricted).
